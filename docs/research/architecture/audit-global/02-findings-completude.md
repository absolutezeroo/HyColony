```
ÉTAT : phase 3 écrite. Code audité : commit 3e2e70ca. Sources : rapports d'exploration (modèle de données, UI,
```

**Avertissement (à reprendre dans le rapport)** : reproduire MineColonies « à l'identique » signifie reproduire ses **comportements, règles, constantes et formules**, pas ses classes. Un port qui recrée `Colony`, `CitizenData`, `AbstractBuilding`, `AbstractEntityAIBasic` ou `InventoryUtils` à la même taille, ou un héritage d'IA sur 4 à 5 niveaux, a copié le défaut avec la fonctionnalité. **Vérifié** : la plus grosse classe du dépôt fait 366 lignes (`CraftingWork`), `Colony` 233, `CitizenData` ~130, `Building` 220, `WorkerStock` 263 ; une seule classe abstraite dans le cœur (`Job`, profondeur 1) ; les IA sont des `JobAI` composés sur `WorkerMachine`. Aucun des défauts structurels de MC n'a été copié.
